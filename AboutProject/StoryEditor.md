# نوشتن بازی بدون کد — راهنمای Story Editor

**The Frayed Red String**

از این به بعد هیچ دیالوگی داخل کد نیست. همه چیز داخل یک پنجره در یونیتی است:

```
The Frayed Red String  ▸  Story Editor
```

---

## ۱. اولین کار: وارد کردن پرده اول

پرده اول قبلا با C# نوشته شده بود. یک بار این را بزن:

```
The Frayed Red String  ▸  Import Act 01 From Code
```

هر ۱۳۲ خط با هر سه ترجمه دقیقا همانطور که هست به یک Asset منتقل میشود
(`Assets/Story/Acts/Act01.asset`) به همراه دو Interlude (موتورخانه و درد پا).

بعد از اینکه نتیجه را دیدی، این چهار فایل دیگر به هیچ دردی نمیخورند و میتوانی
پاکشان کنی:

```
Assets/_C#/Narrative/Act01Script.cs
Assets/_C#/Narrative/StoryInterludes.cs
Assets/_C#/Narrative/StoryScript.cs
Assets/_C#/Localization/Act01Strings.cs
Assets/_C#/Editor/Act01Importer.cs
```

هیچ چیزی موقع اجرا آنها را نمیخواند.

## ۲. ساختن پرده جدید

دکمه **New Act** بالای پنجره. هر هفت پرده با اسم و شماره درست آماده هستند:

| شماره | اسم |
|---|---|
| ۱ | Cherry Blossom Mirage |
| ۲ | Maboroshi |
| ۳ | Serenity |
| ۴ | To Deepen |
| ۵ | Glass Shattering |
| ۶ | Mechanical Room |
| ۷ | Outro |

بعد یک Scene با همان اسم بساز (`Act02.unity` و همینطور تا `Act07.unity`).
داخل Scene فقط این چیزها لازم است:

- یک **Main Camera**
- یک Canvas به اسم `BackgroundCanvas` با یک Image به اسم `GameBackGrundImage`
- (اختیاری) `MenuCanvas` با `LoadGameMenuPanel` و `ChangeLanguageButton` — برای Save/Load داخل بازی

بقیه چیزها (باکس دیالوگ، کاراکترها، منوی توقف، قاب، انتخاب‌ها) خودکار موقع
اجرا ساخته میشوند. **هیچ کدی لازم نیست.**

Scene خودش به Build Settings اضافه میشود.

## ۳. انواع Beat

هر پرده یک لیست از Beat است. سمت چپ لیست، سمت راست تنظیمات همان Beat.
با drag میتوانی جابجایشان کنی، با `+` و `−` اضافه و کم کنی.

| Beat | کارش چیست | منتظر بازیکن میماند؟ |
|---|---|---|
| **Line** | یک خط دیالوگ یا روایت | ✅ |
| **Background** | عوض کردن مکان (با کراس‌فید و اسم مکان) | ✅ |
| **Enter** | آوردن کاراکتر روی صحنه / عوض کردن حالت چهره | ❌ |
| **Exit** | بردن کاراکتر بیرون | ❌ |
| **ClearStage** | خالی کردن صحنه | ❌ |
| **Caption** | نوشتن اسم مکان در گوشه | ❌ |
| **TitleCard** | کارت عنوان پرده | ✅ |
| **Sound** | پخش یک افکت صوتی | ❌ |
| **Music** | شروع آهنگ پس‌زمینه (خالی = قطع آهنگ) | ❌ |
| **Beat** | سکوت. باکس دیالوگ محو میشود و فقط تصویر میماند | ⏱ |
| **Choice** | دکمه‌های آبی/سبز | ✅ |
| **Interlude** | پخش یک پرده کوچک، با احتمال | — |
| **OpenFrame** | باز شدن قاب بازی | ⏱ |
| **CloseFrame** | برگشتن قاب | ❌ |
| **End** | پایان پرده | — |

> **Beat (سکوت) کم‌استفاده‌ترین و مهم‌ترین ابزار است.** دو ثانیه سکوت روی
> تصویر، حرفی را میزند که یک خط روایت خرابش میکند.

## ۴. متن و ترجمه

هر متن سه زبان دارد. بالای پنجره یک انتخابگر **Language** هست — زبان را عوض
کن و کل پرده در همان زبان نشان داده میشود. زیر هر کادر متن، دو زبان دیگر به
شکل دکمه هستند و حالتشان (`empty` یا چند کلمه اول) دیده میشود؛ روی هرکدام
بزنی به آن زبان سوییچ میکنی.

اگر یک ترجمه خالی باشد، بازی انگلیسی را نشان میدهد و کرش نمیکند.

**نوشتن فارسی:** عادی بنویس، مثل هر متن دیگری. پلاگین DirectTMP خودش حروف را
میچسباند و راست‌به‌چپ میکند.

## ۵. صداها

روی هر Beat میتوانی تیک **Play a sound** بزنی و یک صدا انتخاب کنی. دکمه **▶**
کنارش صدا را همانجا داخل ادیتور پخش میکند — لازم نیست بازی را Play کنی.

صداهای موجود:

| صدا | کِی استفاده کن |
|---|---|
| `GiftBox` | کارت عنوان پرده |
| `WishStar` | عوض شدن مکان (خودکار پخش میشود) |
| `PageTurn` | آمدن/رفتن باکس دیالوگ (خودکار) |
| `Petal` | لحظه‌های آرام، شکوفه، باد |
| `Heartbeat` | ترس یوآ |
| `BoilerRoom` | موتورخانه — تنها صدای عمدا زشت بازی |
| `LegAche` | درد پای هارو |
| `ChoiceKind` / `ChoiceCruel` | آبی و سبز |
| `Confirm` / `Cancel` / `Denied` | صداهای منو |

صداهای تایپ (`TypeYua`، `TypeHaru`، `TypeNarrator`) خودکار طبق گوینده انتخاب
میشوند — دستی لازم نیست.

## ۶. آهنگ پس‌زمینه

دو جا میتوانی تنظیم کنی:

1. **Act music** بالای پرده — از اول پرده پخش میشود.
2. **Music beat** — وسط پرده آهنگ را عوض میکند. خالی بگذاری، آهنگ قطع میشود.

اسم آهنگ = اسم فایل بدون پسوند. فایل را بگذار در:

```
Assets/Audio/BackgroundMusics/
```

کنار کادر یک دکمه کوچک هست که لیست آهنگ‌های موجود را نشان میدهد. میتوانی اسم
آهنگی که هنوز نساخته‌ای را هم تایپ کنی — بازی یک warning میدهد و بی‌صدا اجرا
میشود، و به محض اینکه فایل را بیندازی خودش کار میکند.

## ۷. تب Stage — جای کاراکترها و قاب

تب **Stage** بالای پنجره. یک پیش‌نمایش واقعی ۱۶:۹ دارد که همان ریاضی موتور
بازی را استفاده میکند، با بک‌گراند پرده، هر دو کاراکتر، قاب و باکس دیالوگ.

برای هر کاراکتر:

| فیلد | یعنی چه |
|---|---|
| **Offset X** | فاصله از وسط صفحه. بزرگ‌تر = بیشتر به کنار |
| **Height** | قد تصویر روی صفحه (ارتفاع صفحه ۱۰۸۰ است) |
| **Feet Y** | ارتفاع پاها از پایین صفحه. **منفی = پایین‌تر از لبه** |
| **Flip** | آینه کردن تصویر |
| **Side** | کدام طرف صفحه |

> **مشکل «کاراکترها روی هوا هستند» از همینجا حل میشود.** مقدار پیش‌فرض حالا
> `Height = 1500` و `Feet Y = -300` است: تصویر بلندتر از صفحه و پایین‌تر از
> لبه، یعنی از ساق پا بریده میشود به جای اینکه کل بدن با یک حاشیه خالی زیرش
> شناور باشد. عددها را با نگاه کردن به پیش‌نمایش تنظیم کن، نه با Play کردن.

**قاب (Frame):** `Frame Aspect` نسبت تصویر وقتی قاب بسته است (۱.۳۳۳ = ۴:۳).
از پرده اول قاب بسته است. هر جا `OpenFrame` بگذاری، همانجا باز میشود.

> سند داستان باز شدن قاب را در پرده پنجم (شکستن شیشه) میگذارد و تو گفتی پرده
> چهارم. چون الآن یک Beat است، خودت هرجا خواستی بگذارش — کد لازم نیست.

---

## ۸. Interlude — صحنه‌های تکرارشونده

سند میخواهد صدای موتورخانه و درد پای هارو در همه پرده‌ها به شکل تصادفی
پیش بیایند. برای این کار:

1. یک act بدون شماره بساز (**New Act ▸ Interlude**).
2. صحنه کوتاه را داخلش بنویس.
3. در هر پرده‌ای که خواستی، یک **Interlude** beat بگذار، آن asset را انتخاب
   کن، و **Chance** را تنظیم کن (`1` = همیشه، `0.35` = حدود یک‌سوم مواقع).

بعد از Import، `Interlude_MachineRoom` و `Interlude_LegAche` آماده هستند.

---

## ۹. Save و Load

بازی خودش شماره Beat را ذخیره میکند. موقع Load، صحنه و کاراکترها بی‌صدا
بازسازی میشوند و بازیکن دقیقا سر همان خط برمیگردد.

داخل بازی: **Escape** → منوی توقف → Save / Load.

اسم پرده روی کارت Save از خود `Title` پرده خوانده میشود — اسم را در ادیتور
عوض کنی، روی کارت هم عوض میشود.
